# OpenClaw 迁移记录

源工作区仅作为迁移参考，不会在运行时被本项目直接读取。这样项目可以独立版本化、测试和部署，也避免无意依赖用户主目录中的 OpenClaw 状态。

`inventory.json` 是迁移的唯一清单。状态含义：

- `merged`：内容已整理并纳入新项目
- `summarized`：保留任务意图，但尚不可执行
- `review`：需要人工判断哪些内容应成为长期资产
- `deferred`：当前没有迁移价值或等待对应模块
- `rewrite`：保留需求，重新实现，不复制旧运行时代码
- `archive`：历史运行数据，仅用于未来回放/评测
- `reject`：临时状态或环境耦合内容，不迁移
